# Reglugerð um leyfilegan heildarafla á fiskveiðiárinu 2020/2021.

**Nr. 672/2020**

### 1. gr.

Fyrir fiskveiðiárið 1. september 2020 til 31. ágúst 2021 er leyfilegur heildarafli sem hér segir:

| Djúpkarfi | 12.384 |
| Grálúða | 13.271 |

| Gulllax | 8.729 |
| Hlýri | 314 |
| Humar | 0 |
| Hörpudiskur | 93 |
| Íslensk sumargotssíld | 35.490 |
| Keila | 1.429 |
| Langa | 4.430 |
| Langlúra | 854 |
| Litli karfi | 684 |
| Sandkoli | 236 |

| Skrápflúra | 15 |
| Skötuselur | 503 |
| Steinbítur | 8.761 |
| Ufsi | 78.344 |
| Úthafsrækja | 0 |
| Ýsa | 44.419 |
| Þorskur | 254.273 |
| Þykkvalúra/Sólkoli | 1.073 |

### 2. gr.

Reglugerð þessi er sett skv. 3. gr. laga nr. 116/2006, um stjórn fiskveiða. Reglugerðin öðlast þegar gildi.
